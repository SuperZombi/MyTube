    Constructor

    class SubtitlesManager(subs_dict)

      Processes raw subtitles data, providing easy access to subtitles by language code and filtering.

    Parameters:

      subs_dict dict

    Properties

    							subtitles
							dict

      A dict with lang_code and list of Subtitles objects.

    Methods

    							get(lang_code) ->
							list

      Get Subtitles list by iso-code. If not found, returns empty list.

    Parameters:

      lang_code str The ISO language code for the subtitle. 

    							keys()
							list

      Returns the languages keys managed by the instance. 
      yt.subtitles.keys()

    							values()
							list

      Returns flat list of Subtitles. 
      yt.subtitles.values()

    							items()
							dict

      A dict with lang_code and list of Subtitles objects. 
      yt.subtitles.items()

    							len()
							int

      Returns the amount of languages managed by the instance. 
      len(yt.subtitles)

    							iter()

      Allows iteration over the list of subtitles. 
      for code, arr in yt.subtitles:
      	for sub in arr:
      		print(sub)

    							filter(**kwargs) ->
							SubtitlesManager

      Filters subtitles based on various options.

    Parameters:

      ext str Filters to only include extension provided.
      lang str Filters to only include language provided.
      only_autogen bool Filters to only include auto-generated subtitles.
      no_autogen bool Filters to only include manual subtitles.
      custom func A custom filter function that takes a Subtitles object as input.

    Get subtitles with specific language 

    import MyTube
yt = MyTube.YouTube("https://www.youtube.com/watch?v=Xj0Jtjg3lHQ")

lang_code = 'de'
subs = yt.subtitles.get(lang_code)
if not subs:
	print(f"{lang_code} subtitles not found")
else:
	for sub in subs:
		print(f"iso_code={sub.code}, lang={sub.name}, fotmat={sub.ext}")
